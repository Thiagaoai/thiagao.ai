O que está movendo dev + IA

Agentes quetrabalham com você.

Trabalho em cima do que está relevante agora: agentes com ferramentas, sandboxes, MCP, AI SDK, n8n e automações conectadas ao negócio.

AI apps multi-modelo

O AI SDK continua forte para apps TypeScript/Next, abstraindo providers e reduzindo boilerplate para chat, JSON estruturado e tools.

Agentes com sandbox

Agents modernos precisam rodar tarefas em ambientes isolados, com snapshots, guardrails e retomada de estado para trabalhos longos.

n8n como orquestrador

O AI Agent do n8n trabalha como Tools Agent: conecta ferramentas e APIs para decidir e agir dentro de workflows reais.

MCP em produção

MCP virou camada importante para conectar agentes a ferramentas, dados e sistemas, com foco 2026 em escala, governança e enterprise readiness.

LangGraph + LangSmith

Para agentes mais sérios, uso grafos, estado, tracing, datasets e avaliações para depurar comportamento, não só prompt.
